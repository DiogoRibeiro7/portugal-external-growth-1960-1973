Page/table status
-----------------

The PDFs are image scans. Machine text is not reliable, so table discovery is
based on manual image inspection of rendered PDF pages.

Verified source and methodological leads:

- Volume I, PDF page 5: introductory note discusses the list of countries and
  statistical territories, beginning with Portuguese overseas territories.
- Volume I, PDF page 5: introductory note states that countries are grouped
  using the OECD structure, including EEC and EFTA groups.
- Volume I, PDF pages 5-6: introductory note discusses special trade treatment
  for Azores and Madeira and points to tables XII to XVII.
- Volume I, PDF page 23: the list of statistical territories separates
  Ultramar Portugues from foreign countries and lists EEC/EFTA groups.
- Volume I, PDF pages 9-11: explanatory notes define special trade, country of
  origin/consumption treatment, and value conventions.

Double-entry verified aggregate rows:

- Volume I, PDF page 29 / page 38: 1962 special-trade total imports,
  current-money value 16,829,535 in 1,000 escudos.
- Volume I, PDF page 33 / page 39: 1962 special-trade total exports,
  current-money value 10,631,829 in 1,000 escudos.
- Volume I, PDF page 38: 1962 Ultramar imports, current-money value
  2,122,236 in 1,000 escudos.
- Volume I, PDF page 39: 1962 Ultramar exports, current-money value
  2,390,852 in 1,000 escudos.

EEC and EFTA
------------

The source identifies EEC and EFTA groupings, and Quadro III prints individual
country rows, but no directly printed 1962 aggregate EEC/EFTA row has been
verified. These totals remain pending a controlled source-specific aggregation
workflow.

Detailed product rows have not been transcribed.
